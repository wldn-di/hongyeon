1. 처음 접속 시 메인 페이지 (인덱스 페이지)에 접속한다 (https://hongyeon.cloud-ip.cc/)
-> 화면 중앙에 있는 유튜브 영상을 눌러서 홍연 프로젝트의 시놉시스 영상을 바로 시청할 수 있다 
(컨셉 영상, 불안정한 정신세계 속에서 증거물을 쫓아가며 범인을 찾는다는 컨셉)
-> 영상 아래쪽 [튜토리얼 하기] 버튼을 통해서 기본적으로 게임을 플레이하는 방법을 체험 가능하다 ('2-1. 튜토리얼 체험'으로 이동)
-> 영상 아래쪽 [나만의 시나리오 만들러 가기] 버튼을 통해서 본인의 시나리오 생성으로 이동 가능 (로그인 필수, '5. 해당 페이지에서 시나리오 생성을 위해서 필요한 정보들을 입력'으로 이동)

2. 튜토리얼

2-1. 튜토리얼 입장
튜토리얼 시나리오 '첫 번째 사건: 저택의 비밀'을 플레이하게 되며 [수사 시작하기] 버튼을 클릭하여 플레이 시작

2-2. 실제 게임 화면과 동일하게 제공되는 '피해자 정보'를 통해서 피해자 정보 및 수사 근거 확인 (발견 장소, 사망 추정 시각, 사인), 이후 [현장으로 이동] 버튼 클릭으로 튜토리얼 인게임으로 접속

2-3. 튜토리얼에서 왓슨(수사 조수)과의 대화를 따라가며 튜토리얼 진행으로 기본 조작 확인 (본 시연 시나리오에서는 자세한 인게임 기능들을 이후 실제 게임 기반으로 설명)

3. 네브바 우측에 위치한 LOGIN 버튼을 눌러서 Google 로그인을 진행한다, 로그인 후 자동으로 메인 페이지로 복귀

4. 화면 상단 네브바에서 시나리오 버튼을 클릭하여 <시나리오 목록> 페이지로 이동 (https://hongyeon.cloud-ip.cc/scenarios)

5. 시나리오 목록 페이지 내 우측 상단에 위치한 [+시나리오 만들기] 버튼을 클릭하여 시나리오 생성 페이지로 이동 (https://hongyeon.cloud-ip.cc/create-scenario)

그 외에 해당 페이지에서 다른 유저가 생성해 놓은 시나리오들의 확인 및 플레이가 가능하다. 

디스플레이된 리스트에서 목록을 확인하며 본인이 원하는 시나리오를 플레이할 수도 있고 그게 아니라면 시나리오 검색을 통해서 원하는 사건 케이스를 제목으로 찾거나 필터 기능을 통해 장르(범죄/수사, 미스터리, 공포/스릴러), 난이도 (Easy, Medium, Hard)로 분류하여 시나리오들의 확인이 가능하다. 

본인이 원하는 시나리오를 찾고 해당 시나리오의 썸네일 혹은 자세히 버튼을 클릭하는 경우 상세 정보 페이지로 이동하며 (https://hongyeon.cloud-ip.cc/scenario/[시나리오 숫자]) 해당 상세 페이지에서 '게임 시작하기' 버튼을 클릭하는 경우 '8. 인게임 플레이' 단계로 즉시 넘어가게 된다. 

6. 해당 페이지에서 시나리오 생성을 위해서 필요한 정보들을 입력
- 시나리오 제목: 텍스트 형식으로 본인이 원하는 시나리오의 제목 입력
- 스토리 아이디어: 본인인 원하는 전반적인 시나리오의 줄거리 및 시놉시스를 텍스트 형식으로 입력
- 용의자 수: '4명' 혹은 '5명' 버튼 형식으로 제공 둘 중 원하는 옵션을 선택
- 장르: '범죄/수사', '미스터리', '공포/스릴러' 버튼 형식으로 제공 3가지 선택지 중 원하는 옵션을 선택

-> 본인이 원하는 내용을 작성한 이후 화면 우하단에 [시나리오 생성하기] 버튼을 클릭
-> 시나리오 생성을 취소하고 이전 시나리오 목록으로 돌아가기를 원하는 경우 화면 좌하단에 [취소] 버튼을 클릭

7. 시나리오 생성을 마치는 경우 전체 시나리오 (https://hongyeon.cloud-ip.cc/scenarios?sortBy=latest) 혹은 내 시나리오 (https://hongyeon.cloud-ip.cc/scenarios?tab=mine&sortBy=latest) 에서 생성 시나리오 확인 가능
-> 시나리오 리스트 상단 시나리오 검색을 통해서 특정 시나리오 키워드로 검색 가능
-> 장르 / 난이도에 따른 필터링 기능 화면 좌상단에서 제공
-> 최신순 / 인기순 / 별점순 정렬 기능 화면 우상단에서 제공

8. 본인이 생성한 시나리오 혹은 타인이 생성한 시나리오 선택 후 해당 시나리오 클릭 시 디테일 페이지로 진입 (https://hongyeon.cloud-ip.cc/scenario/1) 해당 시나리오 플레이를 원할 시 화면 중앙 하단 [플레이 시작] 버튼 클릭 후 본게임 진입

9. 인게임 플레이

9-1. 프롤로그
각 사건 케이스를 선택하는 경우 해당 케이스에 적합한 프롤로그가 나와 사용자에게 몰입감 있는 시작을 제공합니다. 해당 프롤로그를 읽은 후 '수사 시작하기' 버튼을 클릭하는 경우 피해자의 이름, 나이, 배경 등이 제공되며 초기 단서를 통해서 발견 장소, 사망 추정 시각, 사인 등이 기록된다.

9-2. 증거 획득
불안정한 정신상태를 상징하며 단서 수집을 방해하는 날아오는 사물을 피해가며 (체력 패널티 없이 스턴으로 일정 시간 이동 불가) 사건의 증거 획득을 통한 추리를 목표로 함. Shift키를 눌러서 손전등 켜기/끄기 기능 작동. 손전등이 켜져 있는 상황에 한정하여 단서 습득 가능. 단서 습득은 미니게임을 통해서 가능. 손전등의 에너지는 켜져있는 동안 지속적으로 감소하며 에너지 방전 시에는 자동으로 꺼짐. 손전등이 꺼져있는 동안 에너지는 자동으로 회복된다.

-> 미니게임 1: 자물쇠 맞추기 - 노란 불이 들어온 원형에 맞춰 좌우 화살표로 위치를 맞춘 후 스페이스를 통해서 해제

-> 미니게임 2: 키보드 입력 - 상/하/좌/우/스페이스로 구성된 키를 화면에서 제공하는 순서에 맞춰서 입력

-> 미니게임 3: 균형 유지 - 좌우로 움직이는 포인터가 중앙 공간 안에 들어갔을때 좌우 키보드를 통해서 해당 영역 안에서 포인터가 위치하도록 유지

-> 미니게임 4: 타이밍 맞추기 - 좌측에서 우측으로 움직이는 포인터가 중앙 공간 안에 들어가 있을때 타이밍에 맞춰서 스페이스를 누르면 성공

위 4종류의 미니게임 중 하나가 랜덤으로 플레이되며 성공 시에만 단서 습득 가능 실패하는 경우 다시 해당 아이템을 스페이스를 클릭하여서 도전 가능.

아이템을 획득하는 경우 조수의 증거에 대한 코멘트가 나옵니다.

9-3. 층계 이동 (1 - 6 층)
하나의 시나리오는 6개의 층으로 구성. 엘리베이터를 사용하는 상황에서 랜덤하게 전선 연결 미니게임 등장. 해당 미니게임 클리어 이후 엘리베이터 앞에서 스페이스 클릭 후 위/아래 방향키를 통해서 위층 아래층으로 이동 가능. 각 층계에 처음 진입할 시 조수의 코멘트를 통해서 각 층계의 배경을 유추 가능.

-> 전선 연결 미니게임: 전선의 왼쪽 포인트를 클릭 후 동일한 색상 선의 오른쪽 포인트를 연결하는 방식으로 진행. 4개의 다른 전선을 모두 맞출 시 클리어.

9-4. 범인 탐문
범인의 탐문은 인게임 화면 우하단의 핸드폰 모양 버튼을 클릭하여 대화 화면으로 진입. 해당 화면에서 원하는 용의자를 클릭할 시 대화를 진행 가능한 문자메시지 형태의 UI 진입. 해당 UI에서 채팅창에 본인이 원하는 채팅을 입력하는 방식으로 해당 범인과의 대화 가능. AI를 통해서 실제 인물과 대화하는 듯한 자유로운 상호작용이 가능하지만, 게임 외적인 요소에 대한 질문 및 응답은 제한되어 있다.

-> 대화 기회 차감: 인게임 화면 왼쪽 위 하트를 통해서 차감 상황 확인 가능. 탐문 기회는 20회의 제한 (100의 체력을 가지고 시작하며 한번의 대화마저 5씩 체력이 차감된다)을 가지며 해당 횟수 내에 사용자는 범인을 찾아내야 한다.

-> 증거 제출: 대화를 하는 동안 사용자는 결정적인 증거를 함께 용의자에게 제출할 수 있다. 해당 기능을 통해서 사용자는 의심되는 용의자에게 더 결정적인 증언을 받을 수 있다.

9-5. 추리 보드
수사보드는 그동안 습득한 자료, 탐문 내용, 정황 등을 종합하여 사건의 진상을 밝히는 공간이다. 해당 공간 안에서 사용자는 확정/의심 선을 통해서 증거물들을 연결하게 되며 추리 내용을 메모를 통해서 기록할 수도 있다. 각 기능의 역할은 다음과 같다.

확정 (붉은선): 사건에서 피해자와의 가장 결정적인 연결성을 나타내는 선이다. 해당 선을 통해서 범인(용의자를 피해자와 연결), 범행 장소(범행 장소와 피해자를 연결), 그리고 범행 도구(해당 증거물을 피해자와 연결)을 기록 및 제출하게 되며. 최종 제출의 단계에서 해당 관계도를 통해 수사의 완성도를 평가받게 된다. 그렇기 때문에 최종 제출을 위해서는 항상 3개의 확정선이 존재해야 한다.

의심 (노란선): 사건의 진상을 추리하는 과정에서 피해자와의 관계가 유력함을 나타내는 선이다. 해당 선을 통해서 본인이 원하는 대상을 연결해 관계성을 나타낼 수 있다. 하지만, 해당 선은 최종 제출의 단계에서는 평가 대상으로 고려되지 않는다.

메모: 사건의 진상을 추리하는 과정에서 본인이 작성하고 싶은 내용을 수사보드에 기록해 둘 수 있는 기능이다. 사용자는 장소, 용의자, 증거물 등의 오브젝트 외 본인이 원하는 기록 등을 할 수 있다. 하지만, 해당 기록은 최종 제출의 단계에서는 평가 대상으로 고려되지 않는다.

추리 보드에서 이뤄지는 수사 상황은 추리 보드 상단 우측에 있는 '저장하기' 버튼을 클릭해주어야 저장 및 제출 시 반영된다. 제출 시에는 '피해자'를 중심으로 범인, 범행 도구, 범행 장소를 3개의 확정선으로 이어야지만, '최종 제출'이 가능하다. 이후 이전에 이야기한 조건이 충족되는 경우 '최종 제출' 버튼을 통해서 추리를 제출하게 되면 마지막으로 '범행 동기'를 서술하게 된다. 이후 우선적으로 범인이 맞는지 여부를 통해 추리 성공 여부를 확인하고 범인이 맞지 않는 경우 참여자는 총 3번까지 제출 기회를 부여받는다. 

9-6. 추리 성공/실패에 따른 차이

추리 성공 시
범행의 범인을 정확히 추리하여 연결하는 경우 '최종 정답 제출'을 하게 되는 경우 에필로그가 제공된다. '범인의 자백 보기' 버튼을 클릭할 시 범인의 독백(성공)이 참여자에게 제공되며 해당 시나리오(사건)에 대한 리뷰를 남긴 이후 소요 시간, 탐문 횟수(남은 체력), '확정'을 통해 연결한 주요 관계 및 동기의 정확성 등을 종합해서 평가 및 점수를 부여한다. 이후 '홈으로 돌아가기' 버튼을 누를 경우 홈 화면으로 이동이 가능하다.

추리 실패 시
3회에 걸쳐서 범인 추리에 실패한 상태에서 '최종 정답 제출'을 하게 되는 경우 '수사 실패' 라는 문구와 함께 범인의 '독백 보기' 와 '홈으로 돌아가기' 버튼이 나오며 '범인의 독백 보기' 버튼을 누를 시 범인의 독백(실패) 가 나오게 된다. 독백을 보기 전/후로 나오는 '홈으로 돌아가기' 버튼을 클릭하여 홈 화면으로 이동이 가능하다.

10. 내 수사록
(https://hongyeon.cloud-ip.cc/my-bookshelf)

화면 상단에는 담당한 사건 수, 해결한 사건 수, S 등급, 사건 해결률의 4가지 각 분류에 속하는 사건 케이스들의 수가 출력된다.

담당한 사건 수 - 지금까지 도전했던 모든 사건의 수가 기록된다 (해결한 사건들, 진행중인 사건들, 미제 사건들 모두 포함)

해결한 사건 수 - 범인을 추리하는데 성공한 사건의 수가 기록된다 (해결한 사건들 수 포함)

S 등급 - 최고 등급인 S등급을 받은 추리 사건의 수가 기록된다

사건 해결률 - 플레이한 모든 시나리오 중 최소 1회 추리에 성공한 사건의 해결률이 기록된다

해결한 사건들 / 진행중인 사건들 / 미제 사건들의 3가지 분류로 나의 게임 플레이 기록을 책장에 놓여진 책의 UI를 사용하여 저장. 해당 시나리오의 표지를 클릭하여 다시 게임으로 돌아가서 추리 가능.

해결한 사건들:
해결한 사건들은 범인을 추리하는데 '성공'한 시나리오들이 정리되는 공간이다 (추리 성공 케이스)

진행중인 사건들:
아직 '성공' 혹은 '실패' 로 추리의 결론이 나기 전에 중간 진행 과정 중에 멈춰있는 사건들이 저장되는 공간이다.

미제 사건들:
미제 사건들은 범인을 추리하는데 '실패'한 시나리오들이 정리되는 공간이다 (추리 실패 케이스)

11. 랭킹 페이지
(https://hongyeon.cloud-ip.cc/ranking)

페이지 상단에 총 점수, 클리어 수, 플레이 시간의 3개 항목으로 랭킹 시스템 구성.

총 점수: 플레이하며 추리에 성공한 사건 케이스에서 위에서 얘기한 점수 책정 시스템을 통해 부여된 점수의 총 합을 통해서 랭킹을 기록한다

클리어 수: 추리에 성공한 사건 사건 케이스의 개수를 총합하여 랭킹을 기록한다

플레이 시간: 게임 플레이 시간을 기준으로 랭킹을 기록한다

3개의 탭 아래에 있는 '사용자 이름으로 검색...' 창에 유저의 id를 검색하여 특정 유저의 기록을 확인할 수 있다

추가) 배경 음악 재생/정지 기능

음악 기능은 웹에서의 배경 음악 (메인 테마 1, 메인 테마 2)과 인게임 음악(게임 BGM 1, 게임 BGM 2)으로 구분이 된다. 재생 및 속도 조절은 동일한 UI를 사용하며 화면 오른쪽 아래에 고정된 턴테이블 버튼을 눌러 다음 곡, 이전 곡으로 전환하기, 볼륨 조절, 그리고 정지 등의 기능을 제공한다.
