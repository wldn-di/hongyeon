# 시연 시나리오 (풀 데모)

## 0. 시연 전 준비

### 필수 준비물
- PC 브라우저(모바일은 접속 시 “PC 전용 게임” 오버레이가 떠서 진행 불가)
- Backend 실행: `http://localhost:8080` (health OK)
- Frontend 실행: `http://localhost:5173`
- Keycloak 로그인 가능 상태(구글 계정)

### 사전 체크(1분)
1. `http://localhost:8080/actuator/health` -> `UP`
2. `http://localhost:5173` 접속 -> 홈 화면 로딩
3. 우측 상단 `LOGIN` 버튼이 보이는지 확인(로그인 전 기준)

---

## 1. 홈 화면 소개 (`/`)

1. 상단 좌측 로고 `HONG-YEON` 확인
2. 가운데 소개 문구/영상 영역 확인
3. 주요 CTA 버튼 확인
   - `▶ 튜토리얼 하러 가기`
   - `▶ 나만의 시나리오 만들러 가기` (로그인 여부에 따라 동작이 달라짐)

---

## 2. 튜토리얼 시연 (`/tutorial`)

1. 홈에서 `▶ 튜토리얼 하러 가기` 클릭
2. 화면 우측 상단 `스킵` 버튼으로 빠르게 진행(또는 그대로 진행)
3. 튜토리얼 내 주요 UX 시연 포인트
   - 오프닝(타이핑 텍스트) -> `수사 시작하기`
   - 피해자 프로필 카드 -> `현장으로 이동`
   - (진입 후) 왼쪽 패널/로그 패널/하단 보드 패널 등 UI가 어떻게 동작하는지 10초 정도 보여주기

> 튜토리얼은 헤더가 숨겨져 있으므로, 홈/목록으로 돌아갈 때는
> - 튜토리얼 내 종료/이동 버튼, 또는
> - 브라우저 뒤로가기
> 를 사용합니다.

---

## 3. 로그인 시연 (Keycloak + Google)

로그인은 “보호된 기능 접근”으로 자연스럽게 시연합니다.

1. 상단 메뉴에서 `내 수사록` 클릭
2. 로그인 모달(`로그인이 필요합니다`)이 뜨면, `구글 로그인` 버튼 클릭
3. 브라우저가 백엔드 로그인 시작 URL로 이동하는지 확인
   - `GET /api/auth/login`
4. Keycloak -> Google 로그인 완료 후 프론트로 복귀 확인
5. 우측 상단이 `LOGIN`에서 사용자 메뉴(닉네임/PROFILE/로그아웃)로 바뀌는지 확인

---

## 4. 시나리오 목록/상세 시연 (`/scenarios`, `/scenario/:id`)

### 4.1 시나리오 목록
1. 상단 메뉴 `시나리오` 클릭
2. 검색창에 키워드 1개 입력 후 `검색` 클릭(필터링 반응 확인)
3. 목록 카드에서 `자세히` 버튼 클릭

> 생성 상태가 `생성 중...`인 경우 “자세히”가 막힙니다. `자세히`가 가능한 카드로 진행합니다.

### 4.2 시나리오 상세
1. 상세 페이지에서 제목/줄거리/메타 정보를 보여주며 설명
2. `게임하기` 버튼 클릭
3. 이미 플레이한 시나리오면 “재플레이 확인 모달”이 뜨는 점을 설명 후 확인 진행

---

## 5. 게임 플레이 시연 (`/game/:scenarioId`)

> 게임 화면은 헤더가 숨겨집니다.

1. 오프닝 화면
   - `수사 시작하기` 클릭
2. 피해자 소개 화면
   - `현장으로 이동` 클릭
3. 본게임 진입 후 핵심 기능 1~2개만 빠르게 시연
   - 좌측 패널에서 `증거/용의자/장소` 확인 (호버/클릭 동작)
   - 휴대폰 UI 열기(대화/단서 태그 등)
   - 추리보드 열기(카드 배치/연결/저장)
4. 제출 플로우 시연
   - 추리보드 기반으로 범인/동기/방법 등을 입력하고 제출
   - 제출 후 결과 모달/리뷰 흐름이 뜨면 핵심 메시지만 설명

---

## 6. 랭킹 시연 (`/ranking`)

1. 상단 메뉴 `랭킹` 클릭
2. 상단 탭(랭킹 타입) 전환 동작 확인
3. 검색 입력(2자 이상) 후 특정 유저가 필터되는지 확인
4. 새로고침(우측 상단) 버튼으로 refetch 동작 확인

---

## 7. (옵션) 시나리오 생성 시연 (`/create-scenario`)

> AI 생성은 시간이 걸릴 수 있어 옵션으로 둡니다.

1. 홈에서 `▶ 나만의 시나리오 만들러 가기` 클릭
2. 폼 입력
   - 제목, 스토리 아이디어, 용의자 수, 장르 선택
3. `시나리오 생성하기` 클릭
4. 우측 상단 알림(벨) 또는 상태 패널에서 진행 상황을 보여주며 설명
5. 완료 후 `/scenarios`로 돌아가 생성된 시나리오가 목록에 반영되는지 확인
